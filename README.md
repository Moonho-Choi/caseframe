# CaseFrame — 치과 케이스 사진 배열 도구

치과 케이스 사진(구강 내·안모·방사선)을 십자·격자 배치로 정렬하고, 확대·회전·밝기 보정을 거쳐 전자차트나 PowerPoint에 쓸 PNG 한 장으로 저장하는 무료 웹 도구입니다.

**https://caseframe.kr**

## 특징

- 설치·가입 없이 브라우저에서 바로 사용합니다.
- **사진은 서버로 전송되지 않습니다.** 모든 처리는 사용자 컴퓨터의 브라우저 안에서만 이루어지며, 이 저장소의 코드로 누구나 직접 확인할 수 있습니다.
- 십자 5장(정면·좌우·상하악 교합면)을 포함한 8가지 배치와 배경 5종을 제공합니다.
- 확대·이동·미세 회전·반전·밝기·대비 조절, 실행 취소, 저장 미리보기를 지원합니다.
- 병원 로고, 환자 정보 칸, 자유 글상자를 넣을 수 있고, 해상도 3단계의 PNG/JPG 저장과 클립보드 복사를 지원합니다.

## 도구

- **케이스 사진 배열** (/): 구강 내·안모·방사선 사진을 십자·격자로 배열해 PNG로 저장합니다.
- **선그리기 전용** (/line/): 캡처 위에 직선·곡선을 그립니다.
- **증상 요약** (/sx/): 진료 구술을 차트 문장으로 정리합니다.
- **교정 진행 영상** (/motion/): 교정 진행 사진을 이어 붙여 치아가 움직이는 영상을 만듭니다.

# 교정 진행 영상 도구 화면 개편(v2) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `motion/index.html`과 `motion/js/main.js`를 CaseFrame 선그리기 도구와 같은 화면 문법(검은 바탕, 위쪽 막대, 큰 판 + 조절판, 아래 사진 줄, 전체 화면 끌어놓기)으로 다시 짜고, 저장 버튼을 눈에 띄게 하며, 파일 이름에 품질·날짜를 넣는다.

**Architecture:** 부품 모듈(load/features/orient/align/color/interp/encode/cvready)은 손대지 않는다(단 `encode.outputName` 서명만 확장). `main.js`는 화면 상태 기계(`empty → ready → busy → done`)를 갖고 각 상태에서 topbar 주 버튼·stage·inspector·filmstrip을 갱신한다. CSS·마크업은 `line/index.html`에서 복사해 이름을 유지한다(`topbar/brand/btn/privacy-note/workspace/inspector/control-section/filmstrip/film-info/asset-list/asset/film-hint/#drop/#toast/sheet-empty`).

**Tech Stack:** 순수 HTML/CSS/JS(ES 모듈), 빌드 없음. 시험은 Node `node --test 'motion/test/*.test.mjs'` + 통제자의 크롬 확인.

## Global Constraints

- 설계: `docs/superpowers/specs/2026-09-21-motion-ui-v2-design.md` (§2 화면 문법, §3 배지, §4 주 버튼·파일 이름, §5 첫 화면 아이콘). 색 토큰·글꼴·클래스 이름은 `line/index.html`과 동일하게.
- 부품 알고리즘·`planTiming`·기본 품질은 바꾸지 않는다.
- 파일 이름: `<baseName>_교정진행_<고품질|빠르게|단순>_<YYYY-MM-DD>.mp4`.
- 상태별 주 버튼: 2장 미만 비활성 "영상 만들기" / 준비 "영상 만들기" / 만드는 중 비활성 "만드는 중 N%" / 완성 "MP4 저장" + 0.8초 pulse 2회.
- 남은 시간 표시: 프레임 8장마다 갱신되는 진행 콜백에서 (경과/처리 프레임)×남은 프레임, 10초마다 글씨 갱신, "약 N분 M초".
- 사진은 서버로 나가지 않는다. 크롬·엣지 전용 문구 유지.
- 커밋 메시지 한국어, `Co-Authored-By: <작성 모델 이름> <noreply@anthropic.com>`. 푸시 금지.
- 시험: `node --test 'motion/test/*.test.mjs'` 전부 통과. 브라우저 확인은 통제자가 한다(작업자는 브라우저 없음).


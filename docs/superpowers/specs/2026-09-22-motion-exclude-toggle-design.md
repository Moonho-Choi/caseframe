# 교정 진행 영상 도구 — 제외 토글·고정 번호·각도 검사 버튼 색 설계

작성일: 2026-09-22
상태: 원장 승인 (설계 단계)
바탕: [2026-09-22-motion-angle-check-design.md](2026-09-22-motion-angle-check-design.md). 바꾸는 파일: `motion/js/main.js`, `motion/index.html`, `motion/README.md`.

## 1. 왜

원장이 각도 검사 뒤 ✕로 사진을 빼 보니 목록에서 아예 사라져 다시 넣을 수 없었다. 또 순서를 바꾸면 번호가 따라 바뀌어 무엇을 옮겼는지 알 수 없었다. 각도 검사 버튼은 색이 없어 눈에 띄지 않았다.

## 2. 제외 토글 (개별 삭제 없음)

- 각 사진에 `excluded: boolean`(기본 false). ✕ 버튼 → **토글 버튼**: 포함 상태면 "빼기"(아이콘 ✕, title "영상에서 빼기"), 제외 상태면 "넣기"(아이콘 ↩, title "영상에 다시 넣기").
- 제외된 사진은 격자와 사진 줄에 **그 자리에 그대로** 남고, 흐리게(`opacity .45`, 살짝 회색조) + 회색 배지 **"제외"**. 순서 바꾸기·뒤집기는 그대로 가능.
- 영상 만들기·각도 검사·방향 검사(추가 시 자동 검사)는 **포함된 사진만** 쓴다. 만들기 버튼 활성 조건 = 포함 2장 이상; 각도 검사 = 포함 3장 이상.
- 제외 상태를 바꾸면 캐시·각도 배지 무효화("다시 검사하세요"). 캐시 키에 `excluded`를 포함.
- 개별 삭제는 없앤다. 목록에서 완전히 없애는 것은 "사진 전부 비우기"뿐.
- 각도 검사 배지가 붙은 사진을 빼면 "제외" 배지가 붙고 각도 배지는 재검사 전까지 사라진다(무효화 규칙과 동일).

## 3. 고정 번호

- 사진마다 `no`(정수)를 부여: 처음 넣을 때 날짜순 정렬 후 1부터. 이후 추가되는 사진은 현재 최댓값+1부터(추가분끼리는 날짜순). 순서를 바꿔도 `no`는 그대로.
- 캡션은 `no · YYYY-MM-DD`(날짜 없으면 `no · 이름`). 격자·사진 줄 동일.
- "사진 전부 비우기"를 하면 번호도 1부터 다시.

## 4. 각도 검사 버튼

- `#checkBtn`: 폭 100%, 높이 44px, 글씨 15px 굵게, **파란 그라데이션** `#4DA3FF → #1E6FD9`, 글씨 흰색. 비활성이면 회색·흐리게. 만들기 버튼(주황 52px)보다 한 단계 작게 두어 위계 유지.

## 5. 검사

1. 크롬: 25장 → 각도 검사 → 표시된 사진 ✕(빼기) → 그 자리에 흐리게 남고 "제외" 배지, 캡션 번호 유지 → 만들기 버튼 활성 → 영상에 제외 사진 없음(프레임 수 감소) → ↩(넣기)로 복귀.
2. 순서 바꾸기 뒤 캡션 번호가 그대로인지(예: 3·5·4).
3. 포함 사진이 1장이 되면 만들기 비활성, 2장이면 각도 검사 비활성.
4. `node --test 'motion/test/*.test.mjs'` 통과.

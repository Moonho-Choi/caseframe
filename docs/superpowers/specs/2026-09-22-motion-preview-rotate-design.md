# 교정 진행 영상 도구 — 크게 보기·미세회전·겹쳐 보기 설계

작성일: 2026-09-22
상태: 구현 완료, 공개 대기 (2026-09-22)
바탕: [2026-09-22-motion-exclude-toggle-design.md](2026-09-22-motion-exclude-toggle-design.md). 바꾸는 파일: `motion/js/main.js`, `motion/index.html`, `motion/js/load.js`(회전 함수 추가) 또는 새 `motion/js/rotate.js`, 시험 파일, `motion/README.md`.

## 1. 왜

영상을 만들기 전에 사진을 크게 확인하고, 기울어 찍힌 사진을 손으로 조금 돌려 놓고 시작하고 싶다(원장 요청). 자동 보정은 실험상 한계가 있어 사람 눈으로 맞추는 길을 연다.

## 2. 크게 보기 (viewer)

- 격자 카드의 사진 부분을 클릭 → 가운데 판이 **뷰어**로 바뀐다(`#viewer`, 영상 화면과 같은 자리·크기). `uiState`에 `'view'` 추가(ready에서만 진입; busy/done에서는 진입 불가, done에서 카드를 누르면 먼저 ready로).
- 뷰어 구성: 큰 캔버스(`#viewCanvas`, 사진을 판에 맞춰 contain), 위쪽 캡션 `no · 날짜`, 버튼 줄: `◀ 이전` `다음 ▶` `⇄ 뒤집기` `✕/↩ 빼기·넣기` `닫기`. Esc = 닫기, ←/→ = 이전/다음(입력창에 포커스가 없을 때만).
- 뷰어 아래 줄(조절 줄): **회전 슬라이더** `#rotSlider`(−10~+10, step 0.5, 값 표시 `#rotValue` "+2.5°"), `0°` 버튼, **"앞 사진 겹쳐 보기"** 체크 `#onion`(반투명 50%로 바로 앞 순서의 포함된 사진을 겹침; 첫 사진이면 비활성).
- **확대·축소(보기 전용)**: 캔버스 위에서 마우스 휠로 1~4배 확대(커서 위치 기준), 확대 상태에서 끌어서 이동, `맞춤` 버튼(`#viewFit`, 단축키 0)으로 원래 크기. 사진을 바꾸면 맞춤으로 초기화. 확대는 보기용이며 사진 데이터에는 영향이 없다(크기 보정은 구도 맞추기가 자동으로 함).
- 슬라이더를 움직이면 캔버스가 즉시 갱신된다(회전은 미리보기용으로 캔버스 변환만 사용, 실제 사진 데이터는 §3에서 계산).
- 뷰어를 닫거나 다른 사진으로 넘어갈 때 현재 회전값을 그 사진에 **적용**한다(§3). 별도 "적용" 버튼 없음.

## 3. 회전 데이터

- 각 사진에 `original: ImageData`(처음 읽은 것; 뒤집기 전) — 현재 `image`는 표시·계산용. 이미 `flipImageData`로 뒤집힌 `image`를 쓰고 있으므로, **원본 보관 규칙**: `it.original` = 읽은 직후의 ImageData, `it.rotation` = 도 단위(기본 0), `it.flipped` = 뒤집힘 여부(자동+사용자 토글의 최종 상태). `image`는 항상 `original`에서 `flipped` → `rotation` 순으로 다시 만든다(`rebuildImage(it)`). 누적 재표본 없음.
- 회전 함수 `rotateImageData(image, deg) → ImageData`(순수 JS 없이 캔버스 `ctx.rotate`로 구현해도 됨: 브라우저 전용이므로 main.js 안에 두되, Node 시험이 필요한 순수 함수는 없음). 빈 모서리는 가장자리 색으로: 캔버스에 사진을 1.06배 키워 그린 뒤 회전하는 방식 대신, **회전 후 빈 곳을 `BORDER_REPLICATE`처럼 채우기 위해** 먼저 사진을 캔버스 전체에 그리고, 회전한 사진을 그 위에 그린다(빈 모서리에 원본 가장자리가 비쳐 replicate와 비슷한 효과). 단순·충분.
- `thumb` 캐시 무효화, `cacheKey()`에 `rotation` 포함, 변경 시 `invalidateCheck()`.
- 격자·사진 줄 배지: 회전이 0이 아니면 청록 작은 배지 `회전 +2.5°`.

## 4. 하지 않는 것

- 사진 데이터의 확대·이동 편집은 넣지 않는다(뷰어의 확대는 보기 전용). 편집은 회전만.
- 회전 각도 자동 제안 없음.

## 5. 검사

1. 크롬: 사진 클릭 → 뷰어 → 슬라이더 +3° → 다음 사진으로 이동 → 돌아오면 +3° 유지, 격자 배지 "회전 +3.0°" → 영상 만들기 → 해당 프레임이 회전된 채 나옴(눈으로).
2. 겹쳐 보기 체크 시 앞 사진이 반투명으로 겹침; 첫 사진에서는 비활성.
3. 뒤집기와 회전을 함께 써도 화질 누적 저하 없음(원본에서 재생성).
4. `node --test 'motion/test/*.test.mjs'` 통과(기존 44).

# 교정 진행 영상 도구 — 수동 맞춤 모드 설계

작성일: 2026-09-22
상태: 구현 완료, 공개 대기 (2026-09-22)
바탕: [2026-09-22-motion-preview-rotate-design.md](2026-09-22-motion-preview-rotate-design.md)(뷰어). 원장 판단: 자동 구도 맞추기 결과가 눈에 띄게 어긋나는 사진이 있어 손으로 손볼 수단이 필요. 이전 "미세회전"은 자동 계산에 덮어써져 효과가 없었으므로 **삭제**하고, 자동 계산 **위에 덧붙는** 수동 보정으로 바꾼다. 바꾸는 파일: `motion/js/main.js`, `motion/index.html`, `motion/js/align.js`(보정 행렬 합성 도우미), 시험, `motion/README.md`.

## 1. 데이터

- 사진마다 `it.adjust = { scale: 1, rotation: 0, dx: 0, dy: 0 }`(기본 = 손질 없음). `scale` 0.5~2.0, `rotation` −10~+10도, `dx/dy` 픽셀(기준 틀 좌표).
- 이전 `it.rotation`(미세회전)은 제거한다. `rebuildImage`는 뒤집기만 한다(`original` → `flipped`). 회전 배지·슬라이더·`coverScale`·`drawOriented`의 회전 부분 삭제.
- **보정 행렬** `adjustMatrix(adj, W, H)`: 기준 틀 중심(W/2, H/2)을 축으로 `scale`·`rotation`을 적용하고 `(dx, dy)`만큼 옮기는 2×3 행렬(features.js 규약 `[a,b,tx,c,d,ty]`). `align.js`에 순수 함수로 두고 Node 시험을 붙인다(항등, 배율만, 회전만, 이동만, 합성 순서).
- 최종 변환 = `compose(adjustMatrix(it.adjust), T[k])` — 자동 변환 뒤에 보정. `make()`·`checkAngles()`의 `warpImage` 호출과 `neighborScores` 입력 모두 이 최종 변환을 쓴다. 따라서 손질하면 겹침 점수도 달라진다.
- 캐시: `state.cache = { key, T, status }`로 바꾼다(`aligned` 사진은 더 담지 않고 필요할 때 `warpImage`로 다시 만든다 — 25장 1~2초). `cacheKey()`에서 `rotation`을 빼고 `adjust`는 **넣지 않는다**(보정은 자동 계산 입력이 아니므로 캐시가 그대로 유효).
- `adjust`는 재검사·순서 변경·제외 토글에도 유지된다. `사진 전부 비우기`에서만 사라진다. 뒤집기를 바꾸면 그 사진의 `adjust`는 초기화한다(뒤집힌 상태에서 맞춘 값은 의미가 없으므로) + 토스트 안내.

## 2. 뷰어 = 수동 맞춤 모드

- 진입: 격자 사진 클릭(기존과 같음). 두 상태가 있다.
  - **구도 준비 안 됨**(`state.cache` 없음 또는 키 불일치): 원본(뒤집기 반영)을 크게 보여 주고, 아래 조절 줄 대신 안내 "먼저 각도 검사를 하면 앞뒤 사진과 맞출 수 있습니다" + **`각도 검사` 버튼**(누르면 뷰어를 닫고 검사 실행; 끝나면 같은 사진의 뷰어를 다시 연다).
  - **맞춤 모드**(`state.cache` 유효): 캔버스에 **기준 틀(W×H) 전체**를 보여 주되 현재 사진을 최종 변환(자동+보정)으로 그린다. 잘라낼 창(`alignedSize` 여백)을 얇은 청록 점선 사각형으로 표시해 영상에 들어갈 범위를 알 수 있게 한다. 틀 밖 빈 곳은 어두운 회색.
- **겹쳐 보기** 선택 `#onionMode`: `없음` / `앞 사진`(기본) / `뒤 사진`. 겹치는 사진도 자기 최종 변환으로 그리고 현재 사진을 50% 투명으로 위에 그린다(포함된 사진 중 앞·뒤). 첫/마지막 사진이면 해당 항목 비활성.
- **조절 줄**(맞춤 모드에서만): `크기` 슬라이더 0.50~2.00, step 0.01, 좌우에 `−`/`+` 버튼(0.01씩), 값 표시 `1.03배`; `회전` 슬라이더 −10~+10, step 0.25, 값 표시 `+1.25°`; `이동`은 캔버스에서 **끌어서**(포인터 캡처), 화살표 키로 1px(Shift 10px); `되돌리기` 버튼(이 사진의 보정을 기본값으로). 변경 즉시 캔버스 갱신, 값은 곧바로 `it.adjust`에 저장(별도 적용 단계 없음).
- 보기용 확대: 휠로 1~4배(커서 기준) — 보기 전용, 끌기는 이동 편집이므로 보기 이동(팬)은 두지 않는다. `맞춤` 버튼/0 키로 보기 배율 초기화.
- 이전/다음(◀ ▶, ←/→), 뒤집기, 빼기·넣기, 닫기(Esc·**사진 더블클릭**).
- 캡션 `no · 날짜`는 지금의 두 배 크기(18px 굵게). 보기 배율 표시 `· 2.0배`는 캡션 옆 작게.

## 3. 표시

- 손질된 사진(보정이 기본값이 아님): 격자·사진 줄에 청록 배지 **"수동 맞춤"**.
- 제외된 사진: 격자·사진 줄 모두 **어둡게(밝기 35%)·회색조** + 가운데 큰 기울어진 **"제외" 도장**(반투명 흰 글씨, 테두리). 사진 줄에서도 같은 도장(작게).

## 4. 하지 않는 것

- 보정값 자동 제안 없음. 원근·비틀기 없음.
- 보정은 영상·각도 검사에만 반영되고 원본 사진은 바꾸지 않는다.

## 5. 검사

1. Node: `adjustMatrix` 시험 5개(항등 → 단위행렬; scale 2 → 중심 고정; rotation 90 → 중심 기준 회전 검증; dx/dy → 이동; 합성 순서 = 배율·회전 뒤 이동).
2. 크롬: 6장 → 각도 검사 → 사진 클릭 → 맞춤 모드(점선 창·앞 사진 겹침) → 크기 1.05·회전 +1°·끌어 이동 → 배지 "수동 맞춤" → 만들기 → 해당 프레임이 손질대로 나옴. 다시 검사해도 보정 유지. 뒤집기 시 보정 초기화 토스트.
3. 구도 준비 안 된 상태에서 사진 클릭 → 안내 + 각도 검사 버튼 → 검사 뒤 뷰어 자동 재진입.
4. 제외 도장이 격자·사진 줄에 보임. 더블클릭 닫기. 캡션 크기.
5. `node --test 'motion/test/*.test.mjs'` 통과(44 + 5).

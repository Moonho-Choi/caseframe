# 교정 진행 영상 도구 화면 개편(v3) 설계

작성일: 2026-09-22
상태: 원장 승인 (설계 단계)
바탕: [2026-09-21-motion-ui-v2-design.md](2026-09-21-motion-ui-v2-design.md). v2 공개 직후 원장 소감 4건 반영. 부품 모듈은 손대지 않고 `motion/index.html`, `motion/js/main.js`, `load.js`(글씨 문구 하나 추가)만 바꾼다.

## 1. 글씨(라벨) — 처음 설정대로 한 벌만

- 설정판의 "경과 글씨 넣기" 체크박스를 **선택 하나**로 바꾼다: `글씨` = `날짜`(기본) / `경과 기간` / `없음`.
  - 날짜: 사진 파일 이름의 날짜를 `YYYY-MM-DD`로(예: `2023-07-24`). `load.js`에 `dateLabel(date) → 'YYYY-MM-DD'` 추가.
  - 경과 기간: 기존 `monthsLabel`(시작 / N개월 / N년 M개월).
  - 없음: 글씨 없이.
- 날짜가 없는 사진이 섞이면: `날짜`·`경과 기간` 모두 그 사진 구간은 글씨 없이 간다(선택을 강제로 바꾸지 않는다). 선택 옆 작은 안내 "날짜 없는 사진 N장은 글씨 없이 갑니다"를 그때만 표시.
- 미리보기 = 저장 파일(두 벌 만들지 않는다).
- 파일 이름은 그대로 `<이름>_교정진행_<품질>_<YYYY-MM-DD>.mp4` (글씨 유무는 이름에 넣지 않는다 — 원장 결정 없음, 단순 유지).

## 2. 버튼 배치

- **위쪽 막대**: 로고+제목, 개인정보 문구, `#gpunote`, 전체화면 버튼(`#bFs`)만. 주 버튼 없음.
- **오른쪽 조절판(inspector)** 순서: ① 설정 → ② **`#makeBtn` "영상 만들기"**(폭 100%, 높이 52px, 글씨 16px 굵게, 색 주황 `#FF8A3D`→`#E8641E` 그라데이션, 글씨 `#1A0E05`; 비활성이면 회색·흐리게; 만드는 중 "만드는 중 N%" 비활성) → ③ 진행(막대, 단계 글씨, 남은 시간, 취소) → ④ 결과(길이·해상도·크기·파일 이름 + **`#saveBtn` "MP4 저장"** 폭 100%, 높이 44px, 청록 `.btn.primary`) → ⑤ 도움말.
- **영상 아래 가운데**: `#saveBtn2` "MP4 저장"(청록, 높이 44px) · `다시 만들기` · `사진 전부 비우기`. 완성 순간 `#saveBtn`·`#saveBtn2` 둘 다 `pulse`.
- 결과가 없을 때 ④의 저장 버튼은 비활성(흐리게).

## 3. 전체화면

- `#bFs` 동작: 영상이 있으면(`done`) **`#video` 요소만** 전체화면(`video.requestFullscreen()` → 영상과 재생 조절만 보임). 영상이 없으면 `#stage`(사진 격자)만 전체화면.
- 전체화면 중 `#bFs` 글씨는 **"전체화면 해제"**, 아니면 "전체화면". `fullscreenchange` 이벤트로 갱신(Esc로 나가도 맞춰짐). F 키 동일.
- `document.documentElement` 전체화면은 더 쓰지 않는다.

## 4. 사진 줄·격자 표시

- 아래 사진 줄(`.asset`)의 캡션: `번호 · YYYY-MM-DD`(예: `5 · 2023-02-20`). 날짜 없으면 `번호 · 파일이름앞토막`. 배지(자동 뒤집음/다른 방향?/구도 실패)는 캡션 아래 작은 글씨로도 표시.
- 가운데 격자 카드 배지도 같은 형식(`번호 · 날짜`)으로 통일.
- 캡션 글씨 크기 11px, 한 줄, 넘치면 말줄임.

## 5. 검사

1. 크롬 1440×900: 25장 → 사진 줄 캡션 `n · 날짜` → 글씨 `날짜`로 만들기 → 영상에 `2022-05-18`… 표시 → 결과 칸과 영상 아래 저장 버튼 깜빡임 → 저장 이름 확인.
2. 글씨 `없음`으로 만들면 영상에 글씨 없음. `경과 기간`이면 `시작 / N개월`.
3. 전체화면: 영상 있을 때 영상만, 없을 때 격자만; 버튼 글씨 토글; Esc 후 글씨 복귀.
4. 위쪽 막대에 만들기·저장 버튼이 없고, 조절판의 큰 주황 버튼이 동작.
5. `node --test 'motion/test/*.test.mjs'` 통과(`dateLabel` 시험 추가).

# 교정 진행 영상 (caseframe.kr/motion)

같은 방향으로 찍은 교정 사진을 넣으면 치아가 움직이는 영상(MP4)을 만듭니다.
사진은 컴퓨터 밖으로 나가지 않습니다. **크롬이나 엣지가 꼭 필요합니다** — 사파리·파이어폭스에서는
영상을 만들지 못하고 안내만 나옵니다.

1. 같은 방향 사진만 골라 화면 아래 사진 줄이나 화면 아무 곳에나 끌어다 놓습니다(최대 40장). 넣은 사진은 가운데 큰 판에 격자로 펼쳐집니다. 파일 이름에 날짜(20230724 형식)가 있으면 자동 정렬됩니다.
   사진마다 붙는 번호는 **넣을 때 한 번 정해지고 바뀌지 않습니다**(날짜순으로 1부터, 나중에 더 넣으면 그다음 번호). 끌어서 순서를 바꿔도 번호는 그대로라 무엇을 옮겼는지 알 수 있습니다. 번호가 1부터 다시 매겨지는 것은 "사진 전부 비우기"를 눌렀을 때뿐입니다.
2. 뒤집힌 사진은 자동으로 바로잡고 노란 표시를 붙입니다. 틀렸으면 ⇄ 버튼으로 되돌리세요.
   ⇄로 직접 고친 사진은 나중에 사진을 더 넣어도 자동 판정이 다시 뒤집지 않습니다.
   사진을 클릭하면 크게 보면서 기울기를 손볼 수 있습니다(아래 "크게 보기" 참고).
3. 오른쪽 조절판에서 품질(고품질/빠르게), 한 단계 시간, 글씨를 고르고 조절판 가운데의 큰 주황 "영상 만들기"를 누릅니다.
   글씨는 **날짜**(`2023-07-24`)·**경과 기간**(`시작`, `3개월`, `1년 2개월`)·**없음** 중에서 고릅니다. 날짜가 없는 사진이 섞이면 그 사진 구간만 글씨 없이 가고, 몇 장이 그런지 선택 아래에 안내가 뜹니다.
4. 영상에 넣는 사진이 3장 이상이면 "영상 만들기" 위의 파란 **"각도 검사"** 버튼으로 이웃과 잘 겹치지 않는 사진을 먼저 찾아볼 수 있습니다. 검사가 끝나면 그런 사진에 주황 "이웃과 많이 다름" 배지가 붙고, 조절판 "진행" 아래에 표시된 장수와 중앙값이 나옵니다. 빼지 않고 그대로 만들어도 되지만, ✕로 빼면 영상이 더 매끄럽습니다.
   검사한 뒤 사진을 그대로 두고 만들면 제일 오래 걸리는 구도 맞추기 단계를 건너뜁니다. 사진을 빼거나 넣거나 옮기거나 뒤집으면 배지가 사라지고 "다시 검사하세요"가 뜹니다.
5. **✕는 지우기가 아니라 "영상에서 빼기"입니다.** 누른 사진은 목록에서 없어지지 않고 그 자리에 흐리게 남으면서 회색 "제외" 표시가 붙고, 버튼이 ↩로 바뀝니다. ↩를 누르면 다시 들어갑니다. 뺀 사진도 순서 바꾸기·⇄ 뒤집기는 그대로 됩니다.
   영상 만들기·각도 검사·방향 검사는 포함된 사진만 씁니다. 그래서 포함된 사진이 1장뿐이면 "영상 만들기"가, 2장뿐이면 "각도 검사"가 회색으로 꺼집니다. 목록에서 완전히 없애는 것은 "사진 전부 비우기"뿐입니다.
6. 25장 기준 보통 2~5분 걸립니다. 끝나면 큰 판에서 바로 재생되고, 조절판 "결과" 칸의 "MP4 저장" 버튼과 영상 바로 아래의 같은 버튼이 함께 깜빡입니다. 둘 중 아무거나 누르면 저장됩니다.

## 크게 보기 (사진을 클릭)

격자에서 사진을 누르면 가운데 판이 **크게 보기**로 바뀝니다. 영상 화면과 같은 자리라 둘이 함께 보이지는 않습니다.
`◀ 이전` `다음 ▶`(또는 ←/→)로 사진을 넘기고, `닫기`(또는 Esc)로 나옵니다. 여기서도 ⇄ 뒤집기와 ✕ 빼기·↩ 넣기가 됩니다.

- **미세회전**: 아래 슬라이더로 −10°~+10°를 0.5° 단위로 돌립니다. 슬라이더를 움직이면 화면이 바로 따라오고, `0°` 버튼으로 되돌립니다.
  기울어 찍힌 사진을 손으로 맞춰 놓는 자리입니다. 회전한 사진에는 격자와 사진 줄에 청록 `회전 +3.0°` 표시가 붙습니다.
  회전값은 **다른 사진으로 넘어가거나 크게 보기를 닫을 때** 사진에 적용됩니다(따로 "적용" 버튼이 없습니다). 회전을 바꾸면 각도 검사 결과는 지워지고 "다시 검사하세요"가 뜹니다.
  뒤집기와 회전은 언제나 처음 읽은 원본에서 다시 만들기 때문에, 여러 번 고쳐도 화질이 깎이지 않습니다.
- **앞 사진 겹쳐 보기**: 체크하면 바로 앞 순서의(영상에 들어가는) 사진이 반투명으로 겹칩니다. 앞 사진과 각도를 맞출 때 씁니다. 첫 사진에서는 겹쳐 볼 것이 없어 꺼져 있습니다.
- **확대**: 사진 위에서 휠을 굴리면 커서 자리를 기준으로 4배까지 커집니다. 커진 상태에서 끌면 움직이고, `맞춤` 버튼이나 0 키로 원래 크기가 됩니다. 사진을 넘기면 자동으로 원래 크기로 돌아갑니다.
  확대는 **보기 전용**이라 영상에는 영향이 없습니다. 크기 차이는 구도 맞추기가 알아서 맞춥니다.

촬영 팁: 카메라 각도와 거리를 매번 비슷하게 맞추면 영상이 훨씬 매끄럽습니다. 고품질은 25장 기준 이 도구를 만든 맥에서 약 5분 걸렸습니다. 오래 걸리면 "빠르게"를 고르세요.

인공지능 그림(WebGPU)을 쓸 수 없는 컴퓨터에서는 품질이 "빠르게"로 고정되고 그 자리에 이유가 표시됩니다.
영상을 만드는 동안에는 사진 줄을 건드릴 수 없습니다 — 순서를 바꾸려면 취소하고 다시 만드세요.
오른쪽 위 "전체화면"(또는 F 키)은 영상이 있으면 영상만, 없으면 사진 격자만 크게 띄웁니다.

저장되는 파일 이름은 `이름_교정진행_고품질|빠르게_날짜.mp4` 형식입니다(첫 사진 파일 이름 + 고른 품질 + 만든 날짜).
